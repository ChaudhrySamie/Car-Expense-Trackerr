# Admin announcements for Mile Mint

Use Firebase Console to send announcements to every installed app instance without adding a backend.

1. Open Firebase Console.
2. Go to Engage > Messaging.
3. Create a new campaign with Notifications.
4. In Target, choose Topic and enter: announcements.
5. Write the title and message, then send the campaign.

All users who have the app installed and are subscribed to the announcements topic will receive the message.
